# RTT: native ogbn-arxiv trajectory-tube implementation

This document explains what the executable implements, how it relates to the
provided manuscript, and which details have to be reconstructed when the original
weights and run records are unavailable. The source manuscript is **Reference-Tail
Trust: Certified Probability Floors for Learned Updates Inside a Deployed
Network**, including its Appendices A–H. Its equations, Algorithm 1 and Table 7
define the method. A new training run is required to obtain new results; the
reported paper numbers are not generated by this package.

The original public entry points now delegate to the modules in `src/rtt/core/`. The dataset-local entry points are `experiments/ogbn_arxiv/run_native.py` and `run_native.sh`. The [module map](../src/rtt/core/README.md) identifies each computation's owner. Function names in the equation map below remain available through `rtt.core.api` and the compatibility Python entry point. The shared cross-architecture backend is specified separately in [METHOD_SPECIFICATION.md](METHOD_SPECIFICATION.md).

## Scope and assurance level

The primary executable is `run_rtt_iclr2027_arrhenius.py`. The supported starting
experiment is the native bank-and-attention proposal on **ogbn-arxiv** with the
32-step tanh diffusion incumbent. Data preparation, incumbent fitting, temperature
fitting, proposal and admission-head fitting, placement replay, sequential
calibration, selection, audit and diagnostics are separate stages with persisted
artifacts. The synthetic scale is a computational check, not an arxiv result.

The code reconstructs the paper's mathematical admission and whole-call fallback
structure. Its numerical checker uses float64 recomputation, engineering error
allowances, and independent predicate checks. This is **not a verified
directed-rounding implementation of every primitive** described in Appendix G.
Passing its checks or regression tests does not establish a universal theorem
about the installed PyTorch/CUDA/BLAS/tanh kernels. The real-arithmetic guarantees
in the paper require sound continuation and arithmetic enclosures. Preserve this
distinction in experimental reports and deployments.

## 1. Data and the unit of protection

The official OGB graph has node features, citation edges, class labels, publication
years and official train/validation/test splits. The reconstructed transport is
the symmetrized citation graph with a self-loop at every row:

\[
P=D^{-1}(A+I),\qquad P\mathbf1=\mathbf1.
\]

`GraphOp.mm` multiplies by `P`, while `GraphOp.tmm` multiplies by its actual
transpose. This transpose is generally not a row-normalized graph of its own.
Feature normalization uses fitting data statistics. The exact graph preprocessing
and saved pool IDs belong to the experiment manifest.

An episode is one query set plus a corruption draw on the full graph. It has
`nq` scored nodes. Weights on these nodes sum to one, and unscored support rows
have zero terminal weight. Support rows still participate in message passing and
can receive an intervention if they influence scored rows. The benchmark defaults
to 4,096 scored nodes per call; this is not a neighbor-sampled mini-batch of a
different reference graph.

Labels are used by fitting, calibration and offline evaluation. They must not be
used by the serving decision. Incumbent and adapted paths share the same input,
transport, cache realization and scheduled exogenous replacements. A graph-cache
or stress replacement changes both paths' continuation maps, and its masking
must also enter the derivative and tube calculations.

The intended chronological allocation is:

| Population | Permitted purpose |
|---|---|
| Publications through 2017 | Fit networks and replay placement decisions |
| 2018 | Fit temperature; calibrate and select policies using disjoint allocations |
| 2019 development pool | Design decisions and optional diagnostic sweeps |
| 2019 final audit pool | Evaluate the frozen served policy |
| Reserved nodes | Predictions fixed before a uniform label-inspection sample |
| 2020 | Separate temporal-transfer audit |

Pool membership, seeds and reuse must be saved. Reusing an audit population for a
later design decision is reanalysis, not a new untouched-population evaluation.
Uniformly inspected nodes for the finite-population negative-flip bound cannot
have been scored or labeled by the other stages; they may be unlabeled context.

## 2. Frozen incumbent and internal proposals

For state width `d`, the incumbent follows Eq. (5):

\[
H_0=\operatorname{Enc}(X),\quad
F_j(H)=\alpha H_0+(1-\alpha)
       \{(1-\tau)H+\tau\tanh(PHW)\},\quad
z(H_T)=H_T A+b.
\]

`A` and `b` include the fitted frozen temperature. The main settings are `T=32`,
`alpha=0.1`, `tau=0.9`, and transport spectral norm 1.6. Therefore its global
single-step Lipschitz upper bound is 1.386; the implementation must not assume
that this network is globally contractive. `TanhDiffusionIncumbent.freeze`
normalizes and records the actual exported transport. The effective head diameter

\[
\Gamma_\Delta=\max_{c,c'}\|A_{:c}-A_{:c'}\|_2
\]

is computed from the fitted checkpoint, including its temperature. It is not a
constant copied from the paper's measured checkpoint.

At zero-based depths 16–31, the native proposal returns two candidate
displacements relative to `Hbar=F_l(H_l)`:

1. A state-conditioned convex combination of 16 learned bank vectors, mapped to
   the current state coordinates.
2. A signed one-hop attention proposal from the current call graph.

Norm trimming, a learned node weight, and row-budget trimming bound these
candidates before optimization. Eight disjoint role blocks share coefficients;
the reconstructed role assignment uses query/support status crossed with four
confidence groups. This role rule and the network widths are implementation
choices because the manuscript does not uniquely specify them.

For role `k` and candidate `m`, coefficients satisfy `t_km>=0` and
`sum_m(t_km)<=cap_lk`. The physical step is `v=D_l t`. A block Gram factorization
represents the nonzero physical span, equivalent to `D_l=Q_l Theta_l`. Rank-zero
blocks are skipped. The convex objective, covariance and regularizers are functions
of physical displacement, even when the optimizer retains coefficients to express
the hull constraints.

Candidate-dependent head features are support values from 16 fixed probes and
their negatives:

\[
s_{ij}=\max\{0,\max_m\langle u_j,d_i^{(m)}\rangle\}.
\]

Duplicating or permuting candidates, or inserting points inside the same
**post-trim** hull, preserves these features. Nonlinear trimming means that raw
candidate-hull invariance alone is insufficient. Changing or shortening a vertex
may change the hull and legitimately change the step.

## 3. Trajectory tube and continuation contracts

For a fixed executed trajectory, a tube around state `H_j` has row radii `r_j`.
It encloses the incumbent trajectory and incumbent continuations launched from
every point of every accepted intervention segment. The independent checker
builds it forward, recomputing each factor on the tube already established at that
depth.

For `z_j=(PH_j)W`, preactivation uncertainty for row `i`, unit `u` is bounded by
`(P r_j)_i ||W_:u||`. The maximum tanh derivative on that interval is

\[
\bar s_{j,iu}=\operatorname{sech}^2
 \bigl(\max\{0,|z_{j,iu}|-(Pr_j)_i\|W_{:u}\|_2\}\bigr).
\]

`interval_factors` bounds `||W diag(sbar_i)||2` using a low-rank spectral split
and a residual bound. Its global cap is `||W||2`. The curvature factor uses the
maximum of `|tanh''|` on the interval; the global tanh maximum is
`4/(3 sqrt(3))`. Tube-wide factors are required: a Jacobian evaluated only at the
center is not an enclosure of a counterfactual tail.

The forward recursion is Eq. (9):

\[
r_{j+1}=(1-\alpha)[(1-\tau)r_j+\tau L_j\odot(Pr_j)]
           +\operatorname{rownorm}(v_j).
\]

The backward loss contracts are Eq. (9) and Appendix C, Proposition 3:

\[
\begin{aligned}
\Lambda_T&=\Gamma_\Delta w,&\quad \Xi_T&=\tfrac14\Gamma_\Delta^2w,\\
\Lambda_j&=(1-\alpha)[(1-\tau)\Lambda_{j+1}
       +\tau P^\top(L_j\odot\Lambda_{j+1})],\\
\Xi_j&=(1-\alpha)^2[(1-\tau)\Xi_{j+1}
       +\tau P^\top(L_j^2\odot\Xi_{j+1})]
       +(1-\alpha)\tau P^\top(\mu_j\odot\Lambda_{j+1}).
\end{aligned}
\]

These bound first and second directional derivatives uniformly over labels.
Shared constant state replacements zero the corresponding transition derivative;
their masks enter the tube and backward contracts. Numerical residuals receive
additional allowances in the checker.

The provisional tube used by the optimizer is cheaper and may be imperfect.
The learned growth proxy is a frozen percentile heuristic for allocating room;
it is not a universal bound. At an open depth Eq. (13) assigns a row allowance

\[
\rho_{l,i}=\frac{(H_{\rm row}/\Gamma_\Delta
              -\widehat\Pi_l\tilde r_{l,i})_+}
                   {\widehat\Pi_{l+1}n_{\rm left}}.
\]

Each candidate is scaled so that `cap_lk ||d_i||<=rho_l,i`. Zero caps and zero
directions bypass division. Final row protection is established only by the
recomputed terminal tube predicate.

## 4. Three prices and the robust optimizer

At contract depths the charge is

\[
\sigma_l(v)=\sum_i\Lambda_{l+1,i}\|v_i\|_2.
\]

In the last four depths, shorter incumbent-only continuations provide tighter
prices. Crucially, these continuations start at the **currently executed**
`Hbar_{l+1}` and contain no later adapted interventions. Their terminal prediction
is `p_l`. Their Jacobian applied to the candidate basis produces `delta_z=U_l t`.
The nonterminal window envelope is Eq. (10):

\[
\operatorname{env}_l^+(v)
 =\sum_iw_i[p_{l,i}^\top\delta z_i-\min_c\delta z_{ic}]
       +\tfrac12\sum_i\Xi_{l+1,i}\|v_i\|_2^2.
\]

`min(sigma,env_plus)<=B` is a union of two convex feasible sets. The two branches
are solved separately and the better feasible physical step is retained.
Treating their union as a single convex constraint is incorrect.

At the final depth the head is affine, so Eq. (11) is exact in real arithmetic:

\[
C^+(v)=\sum_iw_i[
\operatorname{LSE}(z_i+\delta z_i)-\operatorname{LSE}(z_i)
                  -\min_c\delta z_{ic}].
\]

This equals the worst cross-entropy increase over every possible class assignment
for that local step. Stable logsumexp is used rather than clipped probability
ratios.

The learned field supplies `a_hat_x=Q.T g_hat`. The field reconstruction uses
label-free current-state features and graph-propagated residual features from a
learned posterior head. It must not require the original incumbent terminal
prediction before the first intervention; otherwise the no-extra-full-rollout
property would be lost. The covariance head supplies per-row positive variance,
projected onto each role's physical span with a fixed regularizer. Cross-role
covariance is zero, but the objective retains one joint uncertainty norm:

\[
\Phi_l(x)=\hat a_x^\top x
       +\kappa_l\sqrt{x^\top\hat\Sigma_x x}
       +\frac{(1+\rho_D)\|v\|_\Xi^2+\rho_x\|v\|_2^2}{2\omega}.
\]

At the terminal depth, replace `0.5*||v||Xi²` by the exact label-independent
remainder `sum_i w_i KL(p_l,i || softmax(z_i+delta_z_i))`; retain the physical
regularizers and the division by `omega`.

The executable uses a barrier Newton solver with conservative gauge/smoothing
surrogates. This is a numerical convex optimization implementation, not the
paper's specific multiplier-bisection implementation. Window and terminal
logsumexp smoothings dominate their corresponding exact maximum terms; the
actual provisional debit is recomputed. Its returned finite solution is checked
again independently. A failed solve or a zero budget admits zero. At contract
depths a role whose candidate slopes are all nonnegative can be screened out.
An infinite calibration radius closes robust admission when covariance is
positive definite on the physical span.

## 5. Whole-call certification and serving

After execution, `Checker` recomputes the trajectory's tube, interval factors,
first/second contracts, charges and robust descent models. Algorithm 1 checks:

1. Aggregate charge plus numerical allowances does not exceed `Hplus`.
2. Every served query row satisfies its terminal bound `Gamma*r_T<=Hrow`, with
   applicable numerical allowances.
3. Each accepted step has a nonpositive recomputed robust descent model.

If initial checks fail, tighter spectral factors are attempted. Persistent
failure serves the incumbent for the whole call from a common cached prefix.
No-step serving is exactly the incumbent. Logits, trajectory and finite values
must also be internally consistent.

The mathematical reason the charges compose is Eq. (14):

\[
J(p^\pi;y)-J(p^r;y)=
\sum_l[V_{l+1}(\bar H_{l+1}+v_l)-V_{l+1}(\bar H_{l+1})].
\]

The reference tails telescope despite originating at adapted states. Their
all-label bounds give the weighted call-level `Dinf` limit. The tube and head
diameter give the per-row probability floor. A positive damage budget permits
some regression. Even a zero observed regression count does not imply zero
population regression risk. Only `Hplus<=zeta`, together with sound arithmetic,
rules out the event `damage>zeta` deterministically.

## 6. Learning and sequential calibration

The paper begins with an already-trained incumbent. The package includes a
bootstrap training stage because no checkpoint is supplied. Its width, encoder,
optimizer, stopping rule and initialization are reproducible reconstruction
choices, not a recovery of the unknown original training history.

Native proposal pretraining minimizes the terminal loss of its norm-trimmed raw
update. Admission heads are then fitted on trajectories produced by the current
policy. At each open depth, `true_slope_field` evaluates the incumbent's
counterfactual tail from `Hbar_{l+1}` and backpropagates its supervised loss.
One reverse pass through the final adapted policy would produce a different
target. Posterior, node-weight, field and covariance training use only the fitting
allocation. The covariance is trained on physical slope errors.

This staged fitting procedure is computationally explicit and trainable. It is
not a recovery of the paper's original joint proposal/solver training with
implicit KKT differentiation. Do not present staged training as an identical
optimizer trajectory or use it to promise the same learned policy.

Each corrector uses the same fitted-call generator and episode indices as the
RTT admission heads. Its hidden width is the nearest feasible integer to the
total RTT-head parameter count; the saved training summary records both counts,
their relative mismatch, the width and the call generator. Integer widths make
exact equality unnecessary and generally impossible. Matching these quantities
does not make the model classes or optimization objectives identical.

Sequential calibration proceeds from the earliest open depth to the latest.
For each depth `l`, fresh episodes are run with earlier radii frozen. The current
score is computed before its own action:

\[
s_l=\sqrt{(a_x-\hat a_x)^\top\hat\Sigma_x^{-1}(a_x-\hat a_x)}.
\]

It is joint over all active physical role spans. With `delta_l=delta_cov*pi_l`
and `n` calibration episodes, use the order statistic at
`ceil((1-delta_l)*(n+1))`; set the radius to infinity if this index exceeds `n`.
This finite-sample rule is not an interpolated percentile. Small smoke runs can
therefore legitimately admit no changes. Rank-zero spans have score zero.

The fixed-member coverage statement is marginal over the calibration and test
episode. Selection based on calibration results needs a fresh post-selection
calibration or a simultaneous construction before claiming the same selected-
member trajectory coverage. The final audit of a frozen served policy addresses
a separate statistical question.

## 7. Evaluation and output geometry

The registered five-component mixture is clean, degree shift, historical cache,
feature noise and edge dropout. Severe stress, which rewrites 30% of rows at
depth 16, is audited separately. Exact original corruption generators are not
fully specified in the paper; the code records reconstructed intensities. Cache
and stress changes are shared by both execution paths.

Per-episode records store incumbent and served loss, gain, accuracy and flips,
certificate outcome, charges and timings. Release outcomes are mutually
exclusive: first-pass release, re-certified release, or whole-call fallback.
The ledger must satisfy `0<=fallback<=first_pass_failures<=N`.

Latency records use measured component sums for a fresh call. They include
feature and proposal preparation, the executed prefix and tail, checking, and
any actual fallback. The paired evaluator may reuse predictions, but recharges
the measured computation needed by every output rule; each row corrector
regenerates its proposal-row features. Mixing and projection pay for their
reference rollout, raw rollout, learned posterior and final output operation.
The raw-only rule pays for its own rollout. Composed row correctors also pay for
the original-reference tail used by their features when it was not already
computed by fallback. Records identify this convention as
`fresh_call_component_sum_cached_work_recharged`, and separately report graph
construction in `latency_with_build_s`. These are audited component sums, not
independent cold-start benchmarks or reproduced paper speed ratios.

Call-level regression uses `damage>zeta`. A one-sided Clopper–Pearson upper bound
is `Beta.ppf(1-delta,k+1,N-k)`, with value one if all calls regress. Independence
is conditional on the frozen graph, masks and episode generator. Stateful
histories must reset independently for a call-level binomial audit; correlated
continual streams require a separate sampling unit.

The betting lower bound on gain is the negative upper confidence bound on mean
damage. The uncapped sequence `c_j` is predictable, nonnegative and independent
of the candidate mean `m`; the actual bet is
`lambda_j(m)=min(c_j, (3/4)/(Hplus-m))`. Reserved-node negative flips use a
hypergeometric bound after predictions are fixed and inspection is uniform.

The floor projection in Eq. (16) solves

\[
p'_c=\max\{e^{-h}p^r_c,q_c/\lambda\},\qquad \sum_c p'_c=1.
\]

The corresponding per-row gain frontier is concave; budget allocation equalizes
marginal gain between unsaturated rows subject to row caps and a weighted call
budget. `rtt_frontier.continuous_floor_frontier` implements the continuous
active-set solution for the supplied distribution `q`, without a budget grid.
Sort `q_c / p_ref_c` in ascending order and let `A` and `B` be the incumbent and
posterior masses of a floor-active prefix. At budget multiplier `eta`, the
consistent threshold and row budget are

\[
\theta=\frac{\eta+B}{A},\qquad
h=-\log\frac{\eta+B}{(\eta+1)A},
\]

with `h` clipped to the row cap. Bisection in `log(1+eta)` enforces the weighted
call budget. The implementation handles zero posterior components, zero-weight
rows, saturation and per-row caps, and records spend, a numerical duality-gap
estimate, floor residuals and normalization residuals. These float64 residuals
do not constitute formal interval verification. The audit's posterior-frontier
policy, `frontier_levels_task` and planted-law output frontier use this routine.
Using a learned cross-fitted posterior makes the result a plug-in diagnostic;
it does not certify a fraction of the unknown Bayes optimum.

The separate generic `water_fill` routine remains available for mixing and
projection comparator curves. It allocates fractional marginal segments on a
piecewise-linear grid and uses a conservative concave surrogate for nonconcave
curves. Those comparator allocations are documented approximations and are not
used to define the continuous output-space frontier.

## 9. Reconstruction register and practical limits

| Item | Reconstruction or limitation |
|---|---|
| Original weights and training records | Not supplied; train new checkpoints and retain hashes/logs |
| State/encoder dimensions | Configurable defaults: 256 state, 512 encoder hidden |
| Role assignment | Query/support status crossed with confidence quartiles |
| Field architecture | Learned current-state/posterior residual features; no hidden terminal-reference prerequisite |
| Covariance architecture | Per-row isotropic variance projected into physical role spans |
| Proposal/head fitting | Staged training on raw proposals and executed admission trajectories |
| Solver | Numerical barrier Newton with conservative branch surrogates |
| Interval numerics | Engineering allowances; no universal directed-rounding proof |
| Corruption intensities/cache history | Explicit reconstructed generator, saved with the run |
| External methods and extra datasets | This document covers the native arxiv backend; the separate dataset interfaces declare their own models and execution backend |
| Paper latency and accuracy | Require new measurement on actual hardware/checkpoints |
| Statistical assurance | Only for the frozen policy, actual records and stated sampling/selection design |

`tests/test_rtt_mathematics.py` exercises actual small dense continuation maps,
their tube enclosure, finite-difference curvature, telescoping, all-label terminal
prices, physical-hull invariance, rank-zero behavior and sequential calibration.
These checks validate the tested computations. They do not replace the missing
original checkpoint, a full ogbn-arxiv run, or numerical verification of every
backend primitive.
